# ChatGPT 跨 App 記憶登場：Computer History 打造個人工作流中樞

## 一句話看懂

OpenAI 針對 macOS 用戶推出 Computer History 功能，能自動索引跨應用程式與瀏覽器的工作軌跡，讓 ChatGPT 具備接續未完任務的全域上下文。

## 這件事的技術與產業意義

傳統大型語言模型（LLM）的互動高度仰賴使用者在對話框內主動貼上 Prompt 或文件，造成嚴重的上下文碎片化。此次 OpenAI 在 macOS 釋出的 Computer History，本質上是將系統級的活動日誌（Activity Log）、螢幕光學字元與語意嵌入向量（Semantic Embeddings）進行結構化整理，建構出本機端專屬的「工作時間軸記憶庫」。當使用者呼叫 ChatGPT 或 Codex 時，AI 能直接跨越 Slack、VS Code、瀏覽器等獨立沙盒，精準檢索過去數小時或數天內的動作背景與程式碼片段。這項架構突破了單一對話視窗的 Context Window 侷限，將被動問答升級為主動式、具備工作流感知（Workflow-aware）的自主代理（Agentic AI），大幅減少重複給定背景提示的認知負擔。
