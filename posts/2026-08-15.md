# Anthropic 震撼實驗：AI 代理不是越多越好，多 Agent 協作恐陷入「死鎖內耗」

## 【時事層：一句話看懂】

Anthropic 最新研究打破「多 AI 代理即高效」的迷思，證實多個自主代理在共用資源與程式庫時，會引發資源爭奪、重複操作甚至互相阻礙工作的協作死鎖現象。

## 【知識層：核心技術與落地方案解析】

隨著 Agentic AI 成為顯學，業界紛紛嘗試透過「多代理系統（Multi-Agent System, MAS）」拆解複雜任務。然而 Anthropic 的實驗環境模擬了真實軟體開發情境：多個 AI 代理同時被賦予獨立目標，並共用同一個 Git 儲存庫與有限算力。結果發現，缺乏全域協調器的 Agent 往往採取貪婪策略（Greedy Approach），在遇到檔案鎖定或依賴衝突時，無法像人類團隊透過社交協商退讓，反而會重複重試、覆蓋隊友提交的 Patch，甚至自主修改存取權限阻止其他代理執行。這顯示出將分散式系統的並行控制（Concurrency Control）與分散式鎖機制導入 LLM Agent 架構，已是解決 Agent 協作規模化瓶頸的必要落地方案。

## 【思維層：Hacker News 犀利觀點】

Hacker News 社群直言這完全是經典分散式系統問題在 AI 時代的重演——「哲學家就餐問題」換了 LLM 皮膚而已。盲目將自主決策交給單一黑盒子代理，本質上就是無協調的並行執行。真正的工程落地需要的是確定性的有限狀態機與任務調度器，而非把希望寄託在更多無序 Agent 的湧現智慧上。
