## 程式碼區塊

```javascript
// 這段刻意寫得很長，用來測試程式碼區塊的橫向捲動有沒有正常運作，而不是把整個頁面撐寬。
export function slugify(input) {
  return String(input).trim().toLowerCase().replace(/\s+/g, '-').replace(/[^\p{L}\p{N}_-]+/gu, '');
}
```
