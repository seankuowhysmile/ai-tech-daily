# 主動記憶與防呆確認成關鍵，Meta 旗艦模型 Muse Wonder 能否靠高階 Agent 站穩超級智慧定位？

> 原始報導：[Meta 打造 Muse Wonder 新模型，結合主動記憶與專注能力強攻 AI Agent](https://technews.tw/2026/10/13/meta-introduces-the-muse-wonder-series/)　—　TechNews

## 一句話看懂

Meta 宣布推出 Muse Wonder 系列旗艦模型，主打跨對話主動記憶與主動專注能力，進攻高難度專業任務與個人化 Agent 市場。

## 這件事的重點

Meta 投入一年多時間與數百億美元布局，推出規模大於輕量化 Muse Spark 的 Muse Wonder 及 Muse Wonder Full。官方指出該系列在基準測試成績足以與 Claude Fable 5.1、GPT-6 Astra 並駕齊驅，並強化了程式設計等複雜任務表現，能應用於解讀合約、分析財務或健康資訊等專業與日常需求。

兩款模型的關鍵在於整合「Active Memory」與「Active Focus」技術。Active Memory 能在跨對話中保留使用者的重要脈絡，並主動檢索相關細節；Active Focus 則能嘗試替代方案、適應新資訊，且在必要時主動提出澄清，在執行關鍵動作前先行確認，被 Meta 視為邁向「個人超級智慧」的重要進展。

在商業化部署上，這款新旗艦的定價也反映了其規模規格。透過 Meta Model API 串接 Muse Wonder，每百萬輸入 token 收費 4 美元、輸出 token 收費 20 美元，使用成本水準大致等同於 GPT-6 Sol 或 Claude Opus 5.5。

## AI 觀點

模型導入主動記憶與行動前主動確認的機制，直指 AI 代理在實際運作時容易遺失脈絡與盲目執行的核心痛點。若能藉由跨對話檢索與自我釐清降低操作偏差，將大幅提升 AI 處理合約或財務等高風險專業任務的實用性。

然而，頂規模型的定價門檻也直接拉高了落地驗證的標準。代理系統在執行長流程任務時，通常伴隨密集的脈絡檢索與多次確認互動，這會放大使用成本；如何在維持複雜決策精準度的同時，讓昂貴的算力支出轉化為合理的投資報酬率，將是進入市場後的關鍵考驗。
