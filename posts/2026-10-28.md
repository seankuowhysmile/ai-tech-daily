# 能操作電腦且價格打對折，中階模型 GPT-6.1 Terra 能否成為 AI 代理落地的主力？

> 原始報導：[OpenAI新模型GPT-6.1 Terra強化視覺與電腦操作，API價格僅Sol一半](https://www.ithome.com.tw/news/179985)　—　iThome

## 一句話看懂

OpenAI 推出中階模型 GPT-6.1 Terra，主打強化視覺判讀與電腦操作能力，API 價格僅為 Sol 的一半，並同步降低錯誤率與任務成本。

## 這件事的重點

OpenAI 的模型能力依序為 Luna、Terra、Sol 及 Astra。GPT-6.1 Terra 雖屬於中階定位，且官方仍建議複雜程式設計應使用 Sol 或 Astra，但 Terra 在視覺判讀與電腦操作上已接近高階模型，具備更快速度與更佳的技術溝通能力。其 API 標準價格為每百萬輸入詞元 1 美元、輸出 5 美元，價格僅為 GPT-6.1 Sol 的一半，現已開放 API 及 ChatGPT Work 與 Codex 等付費用戶使用。

在具體性能評測上，Terra 在專業工作測試 Agents’ Last Exam 中得分比前代 GPT-5.6 Terra 高出 15 個百分點，每項任務成本降至前代的三分之一；評估指令列解決問題的 Terminal-Bench 4.0 測試中，則達到 50.3% 的任務解決率。此外，在容易引發錯誤的提示詞內部測試中，其低推理強度的錯誤率也從前代的 53.6% 降至 16.7%，顯著改善了事實正確性。

## AI 觀點

GPT-6.1 Terra 的發布顯示 AI 模型開發策略正從盲目追求極限運算性能，轉向重視實用性與成本效益。透過大幅調降 API 價格與單次任務成本，能降低企業將電腦操作代理（Agent）整合進日常業務流程的門檻。

針對電腦操作與指令列等特定工作場景進行特化，代表中階模型也能在專用領域發揮接近旗艦款的能力。這將有助於開發者在軟體部署、自動化測試等複雜工作上，找到成本與效能之間的最佳平衡點。
