# 告別帳密外洩焦慮：ChatGPT「無憑證代辦」如何打通 AI Agent 落地最後一哩路？

## 一句話看懂

OpenAI 正式升級 ChatGPT 任務代辦功能，讓 AI 代理人在完全不接觸使用者明文帳號密碼的情況下，安全登入外部網站完成日常委託。

## 這件事的技術與產業意義

過去讓 AI Agent 執行跨網站任務（如代訂票券或操作企業內部系統）的最大瓶頸在於憑證託管。傳統做法需要使用者直接提供帳密或常駐 Cookie，極易因提示注入攻擊（Prompt Injection）導致機密外流。本次 OpenAI 引進類似 OAuth 委任與安全隔離 Enclave 的互動協議，使 AI 能在隔離的沙箱環境中透過受限的工作階段權杖（Session Token）與目標網站溝通。Agent 僅能調用經過授權的具體 API 或在特定瀏覽器實例中執行預定義動作，無法讀取、匯出或持久化儲存使用者的原始登入資訊，從架構層面斬斷了憑證遭截獲的風險。

## Hacker News 社群怎麼看

Hacker News 社群普遍肯定這項進展，認為這是推動 Agentic Web 的正確方向，但多數資深工程師依舊抱持審慎態度：即使帳密沒有洩漏，AI 代理人仍可能在被惡意網頁欺騙的情況下執行「非使用者預期」的操作（例如轉帳或下單錯誤商品）。真正的核心難題不是憑證本身，而是授權邊界（Authorization Boundary）與非同步動作的不可逆性，防範 Prompt Injection 引發的邏輯越權依然是未解之謎。
