# 不買 GPU 改搶 CPU？Anthropic 砸百億美元雲端肥約背後的邊緣算力盤算

> 原始報導：[Anthropic向Akamai採購116億美元CPU算力，取得最高5%認股權](https://www.ithome.com.tw/news/179230)　—　iThome

## 一句話看懂

生成式 AI 獨角獸 Anthropic 宣布向 CDN 巨頭 Akamai 承諾長達七年、總額上看兩百億美元的運算合約，重心直指 CPU 負載。

## 這件事的技術與產業意義

在大眾聚焦 GPU 算力軍備競賽的同時，AI 應用的架構正迎來分工轉折。大語言模型在推論階段並非只仰賴 GPU 矩陣加速，前期的輸入 Token 清洗、向量資料庫檢索（RAG）、程式碼沙箱執行以及頻繁的工具調用（Tool Calling），都需要高密度、具備優異單核效能與低 I/O 延遲的 CPU 資源支撐。

Akamai 憑藉龐大的邊緣節點網絡與低延遲分散式架構，能有效分擔 Anthropic Claude 代理人在用戶端動態請求的預處理與路由。這筆交易不僅代表推論架構正走向「GPU 主理模型矩陣、CPU 主控周邊邏輯」的混合運算模式，更讓新創藉由認股權綁定基礎設施供應商，開創兼具資本與資源對賭的新商業範式。

## Hacker News 社群怎麼看

許多工程師在討論區直指，這證明了『雲端巨頭溢價』已逼近極限。微軟與亞馬遜提供的全包式 GPU 集群雖然強大，但網路出口頻寬與邊緣轉發費用高得驚人。Anthropic 轉向邊緣網路業者，本質上是在算力架構上做精細化財務工程。

然而，反對者也質疑，以股票認購權交換長期硬體綁定，就像是把自己的命運押在特定邊緣雲架構上。萬一未來一年內晶片業者推出高整合度的 NPU/CPU 整合架構，這份長達七年的百億級 CPU 承諾，是否會變成難以脫身的沈重技術債？
