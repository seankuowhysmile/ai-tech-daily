# 用更少 token 搞定高難度任務，GPT-6.2 雙模型如何提升真實工作的協作效率？

> 原始報導：[GPT-6.2 Astra / Sol 雙模型登場，更少的 token 搞定高難度任務](https://technews.tw/2026/11/18/openai-introduces-gpt%e2%80%916-2-astra-and-gpt%e2%80%916-2-sol/)　—　TechNews

## 一句話看懂

OpenAI 推出 GPT-6.2 Astra 與 GPT-6.2 Sol 雙模型，主打以更少的輸出 token 處理複雜專案與日常 Agent 流程，並已開放 ChatGPT 付費用戶與 API 使用。

## 這件事的重點

OpenAI 推出全新 GPT-6.2 Astra 與 GPT-6.2 Sol 兩款模型。其中 GPT-6.2 Astra 專為複雜專業專案設計，能製作更貼合範本與領域慣例的投影片、試算表與文件，並在前端網頁、3D 設計及 Codex 程式測試上提供更簡潔的程式碼與較少修改次數；GPT-6.2 Sol 則著重於高效與多功能，能流暢執行多步驟 Agent 工作流程，適合日常協作。

在收費與使用權限方面，兩款模型已開放給 ChatGPT Plus、Pro、Enterprise 及 Edu 用戶使用。API 費用部分，GPT-6.2 Sol 維持前代價格；GPT-6.2 Astra 每百萬輸入 token 收費 8 美元、快取輸入 0.40 美元、輸出 token 40 美元，輸入與輸出價格較 GPT-6 Astra 降低 20%，快取輸入降低 60%，顯著降低每項任務的執行成本。

## AI 觀點

大型語言模型的發展焦點正逐漸從單純的能力突破，轉向單位 token 效益與真實場景的精準度。當模型可以用更少的輸出 token 完成高品質的程式碼與文件，不只直接幫企業降低 API 調用費用，也能讓使用者在相同的用量限制下完成更多任務。

此外，進一步優化範本對齊與多步驟 Agent 流程，顯示 AI 工具正朝向更符合職場慣例的隱性需求邁進。這類強調低成本與高效益的模型更新，將有助於加速企業在日常營運與軟體開發中導入自動化協作。
